# ART_DIRECTION · 起家

美术路线：AI 生图（火山方舟 doubao-seedream-5-0-flash-260915，1536×1536，每张约 0.12 元，本轮上限 10 元）。画风：水墨淡彩，毛笔勾线加一层很淡的水色，像旧画里的农家院落。
参考作品只借构图、材质、色光、信息原则，不复制角色、地图、界面、资产。

这一页写给出图的人和改界面的人。目标图在 `design/targets/`，风格线的样张在 `design/style_line/`，提示词在 `assets/gen/prompts.json`。玩测的人点头之前，不批量出图。

## 1. 视觉原则

- **住了三代的旧院子。** 桌面有划痕，衣裳打补丁，墙上有水渍，没有一件东西是新的、亮的、对称完美的。新买的家具也照旧物画，只是补丁少一块。
- **墨定形，色只是一层水。** 每件立着的东西都有一圈深墨外轮廓，里面平涂一两层浅色。缩到 48 像素一格还认得出靠的是墨线，不靠纹理。画面里出现厚涂、写实光影、3D 高光，就是错的。
- **纸是底，红是事。** 院墙外、没盖起来的屋子都是空白宣纸。整个画面只有两种浓色：朱砂红只给「你选中的人」和「出了事」（生病、钱不够），藤黄圈只给「地上有东西可捡」。别的地方用了大红大黄，就是错的。

## 2. 语法：一眼认出

| 对象 | 轮廓 / 尺度 | 密度 | 怎么和别的区分 |
|---|---|---|---|
| 小人（选中的） | 正侧面剪影，大人约 76 像素高（1 倍缩放），头身比约 1:4，头和手偏大 | 一屋最多四五个 | 脚下一圈断续的朱砂笔圈；头顶一张纸条写名字、在做什么、一道朱砂进度线 |
| 小人（其他的） | 同上；老人背驼约 66 像素，孩子约 54 像素 | 同上 | 只在头顶写一行墨色名字，不带纸条、不带圈 |
| 家具、固定物件 | 斜俯视看得到顶面和正面；宽度不超过占地格子的九成，往上最多超出占地一格半 | 一间屋 3–6 件 | 有完整的墨线外轮廓，颜色是赭石、淡墨灰为主，底部一小片淡墨影子把它按在地上 |
| 脏乱（碎屑、鸡粪落叶） | 扁扁贴地，约一格大，没有高度 | 一屋 0–4 摊 | **不勾线**，只有焦墨干点和一片浑浊水渍；家具永远有线，脏乱永远没线 |
| 掉落物（铜钱、鸡蛋、银簪） | 约半格大，勾线清楚 | 全院同时 1–2 个 | 底下垫一块白纸圆片，外面一圈藤黄虚线圈，右上角一个小亮星 |
| 地标 | 井、石磨、葡萄架、供桌：比家具大一号，墨线更重 | 每处一件 | 院子靠石磨和葡萄架认，堂屋靠供桌和饭桌认，井台靠井认 |

## 3. 颜色和光编码状态

调色板（只用这些）：墨 #2B2622、淡墨灰 #A39C90、赭石 #B9835A、藤黄 #D9B65C、花青 #5E7F8F、汁绿 #8FA37A、米白纸 #ECE5D5，朱砂 #B5443A 只用在第 1 节说的地方。

| 状态 | 色调 / 光 | 不依赖颜色的提示 |
|---|---|---|
| 小人健康 / 生病 | 生病时人物褪掉一半颜色、偏灰绿 | 头顶多一只冒热气的药碗；底部条的状态词里病名和「虚弱」加朱砂框；拆件动画里低头、咳嗽（`cough` 动作） |
| 干净 / 脏乱 | 地面不变色 | 脏乱是一摊摊没有线的墨点，数得出几摊；人走过去铲的时候头顶写着「拿铁锹铲掉院里的鸡粪」 |
| 白天 / 夜里 | 夜里整屋乘花青色调（游戏已有的 `NIGHT_COLOR` 0.45, 0.5, 0.7）；油灯、灶火、供桌烛台各打一团暖黄光 | 睡着的人身子压暗（已有的 `ASLEEP_DARKEN`），旁边写一个「睡」字；界面不跟着变暗，夜里照样看得清字 |
| 盖好的 / 没盖的屋子 | 盖好的有地面颜色、墙、墨线框 | 没盖的只有白纸、一圈虚线、极淡的斜排线，正中写屋名和「加盖 600 文」 |
| 钱够 / 钱不够 | 钱不够的按钮变灰 | 按钮上的字从「买」换成「钱不够」 |

地面贴图进游戏时乘一层米色、对比度降到一半左右（`modulate`），这样人和家具浮在上面。目标图就是这样做的。

## 4. 界面信息层级

- **常驻**：底部条（96 像素高）从左到右是头像、名字和「岁数 · 营生等级」、在做什么和进度、身上状态（用词，不用条）、钱和存粮、五个按钮（家谱、集市、账房、摆设、设置）。左上角两枚圆印：罚、赏。
- **按需**：集市、账房、家谱、设置都是正中弹出的面板，560 宽，压一层半透明暗色在房子上，关掉回到房子。
- **瞬时**：屏幕上方正中的纸条提示，最多 4 条，3 秒消失；小人头顶的「赏」「罚」飘字。

界面风格契约（每一屏照这张表，不各自发挥）：

| 项 | 定法 |
|---|---|
| 底色 | 米白宣纸，带细纸纹 |
| 边框 | 底部条顶上一道花青绫边加一条毛笔墨线；面板四周一圈花青绫边，里面一道细墨线，像册页装裱 |
| 按钮 | 米白底、墨线方框、宋体粗字；禁用时淡灰底、细灰框、字换成原因 |
| 强调色 | 朱砂：选中、病、警告；藤黄：可捡的东西 |
| 字体 | 标题和按钮用宋体粗，正文宋体常规。目标图借用 macOS 自带的宋体，它不能随游戏发布；正式用的字体见第 9 节 |
| 图标 | 和素材同一画法的小墨画（药碗、铜钱），不用线性图标 |
| 提示纸条 | 米白纸条，左边一道朱砂竖条 |

## 5. 关键游戏时刻

### 时刻一：晌午院子（`design/targets/01_晌午院子.png`）
晌午，光从左上斜着打进院子，石磨把一小块影子压在泥地上。镜头停在院子中间，程大柱拖着铁锹往葡萄架那边走，脚下一圈朱砂笔圈，头顶纸条写着「拿铁锹铲掉院里的鸡粪」，朱砂线走到三成。他脚边那摊枯叶和墨点没有一根轮廓线，和身后带墨框的石磨一看就是两种东西。堂屋里柳晚晴就着门口的亮光缝衣裳，苏素纨坐在矮凳上剥豆子。屏幕上方飘过一张纸条：捡到鸡窝外的鸡蛋，卖了 6 文。玩家的眼睛先落在朱砂圈上，再落到右上角那个藤黄虚圈：一串铜钱掉在葡萄架边。左边两间屋子是空白纸和虚线，写着「加盖 600 文」「加盖 1200 文」。前一帧大柱刚蹲在门槛上扒完饭，后一帧他弯腰铲土。玩家看一眼那串铜钱，再看底部条上的 200 文够不够盖西屋。

### 时刻二：夜里伤风（`design/targets/02_夜里伤风.png`，不开面板的一张是 `02b_夜里伤风_无面板.png`）
夜里，整座院子沉进一层花青。只有堂屋供桌的烛台和卧房的油灯各晕开一团暖黄。卧房里柳晚晴弓着背咳，脸色褪成灰绿，头顶一只冒热气的药碗，脚下的朱砂圈在暗处格外扎眼。孩子在炕边，旁边一个「睡」字。玩家点开集市：老姜红枣丸，治伤风，30 文。手头 26 文。按钮上两个字：钱不够。底部条上「伤风」「虚弱」两个词框着朱砂。前一帧她还在灯下缝补旧衣裳，后一帧玩家关掉面板，去账房翻还能卖什么。

这一幕是本作最怕玩家看错的地方：病了的人、缺的钱、买不起的药，三样东西都要在一屏里认出来，靠的分别是药碗、底部条的数字、灰掉的按钮，没有一样只靠颜色。

## 6. 素材规格和角色动画

| 项 | 定什么 | 本作 |
|---|---|---|
| 视角 | 俯视 / 斜 45° / 侧面横版 | 斜俯视：游戏的格子是 48×36（纵向压成四分之三），屋子后墙是一条 30 像素的墙带，所以物件画成从斜上方看、顶面和正面都露出来；地面贴图正俯视画、进游戏纵向压到 0.75 |
| 一格多大 | 屏幕像素 | 1 倍缩放下 48×36。游戏缩放 0.66–2 倍，素材按 2 倍出（一格 96×72），放大不糊 |
| 人物多高 | 屏幕像素（1 倍） | 大人 76–78，老人 66（驼背），孩子 54。现在的白盒小人 28×44、点击框也是这么大，接进素材时要一起放大到约 32×78 |
| 画风精度 | 线条粗细 | 1 倍缩放下外轮廓墨线不细于 2 像素；内部线可以细到消失；纹理只是几笔意思，缩小后糊掉也不影响认 |
| 角色动画 | 派生帧 / 帧表 / 骨骼拆件 | 骨骼拆件（`cutout-animation`，`rig.humanoid_side.json`）。逐帧生图每帧长相会变，拆件的人永远是同一套图 |
| 拆件清单 | 每人 6 张图，拼 10 个部件 | 头连脖子、躯干（肩到胯，不带胳膊）、上臂（连袖子）、前臂连手、大腿（连裤腿）、小腿连鞋；远侧胳膊腿复用近侧的图压暗。关节两头画圆头 |
| 角色朝向 | 4 方向 / 左右镜像 | 只画正侧面朝右，往左走根节点 `scale.x = -1`。正侧面最像皮影，也最好拆 |
| 动作 | 走、待机、干活 | 走、待机用默认动作表；铲、扫、织、咳、睡这些家务动作按 `cutout-animation` 第 4 步往动作表里加几行；睡觉要一个躺姿（目标图里孩子还站着，等这一行补上） |
| 背景 | 图块 / 整张场景 | 按材料出无缝贴图：屋里青砖地、院里泥土地、白灰墙带；房间的墨线框、后墙梁、没盖的虚线框由游戏代码画。整张手绘的房间底图可以以后再加，列为可降级 |
| 物件 | 怎么落地 | 底边对齐占地格子的下沿，宽度不超过格子的九成；物件图自带一小片淡墨影子 |

### 水墨淡彩怎么在小尺寸下不丢
1. 墨线做主角：提示词要求外轮廓粗、内部线少，缩到 1 倍还剩一圈清楚的边。
2. 地面退后：地面贴图乘米色、降对比，人和家具才浮得出来。
3. 浓色留给事：朱砂和藤黄只出现在第 1 节说的地方，其余一律低饱和。
4. 纸纹只铺在地上和界面底上，人物和物件上不铺，免得糊成一片。

### 出图时学到的几条（已经写进 `assets/gen/prompts.json` 和 `manifest.csv` 的备注）
- 物件和小东西用浅灰白底 #F0F0F0。用品红底时，模型画的淡影子会染成粉色，抠不干净。
- 地块图四周自带一圈纸边：处理前先裁掉四边 64 像素再跑 `make_seamless.py`，否则平铺后每块中间有一道白缝。提示词也加了「四条边不留白边」。
- 站立参考图脚下总带一团影子，抠完剩一块绿印：参考图只拿来给拆件图当长相参考，游戏里的人走拆件。
- 拆件图要写「只有一条胳膊 / 一条腿，不是一双」「躯干上完全没有胳膊」，第一版提示词出来的是一双腿和带胳膊的躯干。现在的拆件还有两处毛病：躯干肩口露出一个圆洞（上臂盖住时看不见，抬手时会露），膝盖接缝有台阶。正式批量前再调一版提示词。
- 生图服务要绕开本机代理：`ark.cn-beijing.volces.com` 走代理会在握手时断开，出图时给 `NO_PROXY` 加上 `.volces.com`。

## 8. 目标图

拼的素材全部来自火山方舟 doubao-seedream-5-0-flash-260915（2026-11-18 生成），经 `process_inbox.py` 和 `split_parts.py` 处理；界面全部是脚本画的。商用条款还没查，接进游戏前补进 CREDITS.md。

目标图比现在的游戏多出几样，都是提议，要游戏那边点头才改：只有选中的人头顶有纸条，其他人只写名字；集市里每样药写它治什么（「治伤风」）、标题旁写「手头 26 文」；底部条的病名框朱砂；掉落物外的藤黄虚圈。

可读性自查（看 01 和 02b）：选中的人靠朱砂圈和纸条一眼找到；脏乱没有墨线、家具有墨线，并排放着分得开；没盖的屋是白纸和虚线，和盖好的差一整层颜色。夜里那张，人和家具还是读得出来，但院子里的东西偏暗，镜头外再加一盏灯会好些。

## 9. 待玩测的人定
- 人物大小：A. 现在的 76 像素（一屏能看到四五个人和整间堂屋）；B. 90 像素（人更清楚，堂屋显得挤）；C. 64 像素（更像远看一幅画，脸看不清）。
- 正式字体：A. 霞鹜文楷（楷书味，最像题字，开源可商用）；B. 思源宋体 / Noto Serif SC（端正，和目标图最像，开源可商用）；C. 继续用游戏现在的 Noto Sans SC（黑体，最清楚，最不像画）。
- 屋里地面：A. 现在的淡青砖方格；B. 更淡、几乎看不出砖缝的一层灰（更像留白的画）；C. 每间屋换一种地（堂屋青砖、卧房夯土、灶间泥地），房间更好认，要多出两三张图。

## 停靠点
用户的话：
