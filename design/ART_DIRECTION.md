# ART_DIRECTION · 起家

美术路线：AI 生图（火山方舟 doubao-seedream-5-0-flash-260915，1536×1536，每张约 0.12 元）。画风：A 暖色手绘卡通，玩测的人在 `design/style_compare/00_画风对比.png` 里四选一挑的。上一版水墨淡彩她觉得「太水墨、不够通用」，那一版的图和说明留在 `design/archive_ink/`。
参考作品只借构图、材质、色光、信息原则，不复制角色、地图、界面、资产。

目标图在 `design/targets/`，风格线验收图在 `design/style_line/00_风格线验收图.png`，提示词由 `assets/gen/make_prompts.py` 生成到 `assets/gen/prompts.json`（画风 A 的条目以 `a_` 开头）。玩测的人点头之前，不批量出图。

## 1. 视觉原则

- **旧得可爱的农家院。** 东西都用了很多年：边角磨圆，颜色褪了一点，衣裳偶尔一块补丁。不脏、不破、不阴森。崭新发亮的家具是错的，破败发霉的也是错的。
- **一圈棕线，一层暖色。** 每件立着的东西都有一圈均匀的深棕描边（#4A3424），里面平涂暖色，加一层柔和暗面和一点高光。缩到一格 48 像素还认得出，靠的是描边和大色块。写实光影、3D 质感、像素风，都是错的。
- **番茄红是事，天蓝是捡。** 画面里番茄红只给「选中的人」和「出了事」（生病、钱不够）；天蓝只给「地上有东西可捡」。别的地方再暖再亮，也不用这两个色。

## 2. 语法：一眼认出

| 对象 | 轮廓 / 尺度 | 密度 | 怎么和别的区分 |
|---|---|---|---|
| 小人（选中的） | 正侧面，大人约 90 像素高（1 倍缩放），头身比约 1:4.5 | 一屋最多四五个 | 脚下一圈番茄红实线圈，头顶一个番茄红小三角，再上面一张圆角奶油色名牌：名字、在做什么、番茄红进度条 |
| 小人（其他的） | 老人背驼约 74 像素，孩子约 62 像素、头身比约 1:3 | 同上 | 只在头顶写名字，白边描字，不带名牌、不带圈 |
| 家具、固定物件 | 斜俯视，看得到顶面和正面；宽不超过占地格子的九成，往上最多超出占地 24 像素 | 一间屋 3–6 件 | 完整的深棕描边，颜色明快；底下一小片柔和的棕色影子 |
| 脏乱（碎屑、鸡粪落叶） | 扁扁贴地，约一格大，没有高度 | 一屋 0–4 摊 | **没有描边**，颜色灰暗发褐。家具永远有线、颜色亮；脏乱永远没线、颜色灰 |
| 掉落物（铜钱、鸡蛋、银簪） | 约半格大，有描边 | 全院同时 1–2 个 | 底下一块浅蓝圆片，外圈天蓝实线，旁边两颗天蓝小星 |
| 地标 | 井、石磨、葡萄架、供桌 | 每处一件 | 院子靠石磨和葡萄架认，堂屋靠供桌和饭桌认，井台靠井认 |
| 房间 | 屋里每间换一种地：堂屋青灰方砖，卧房蜂蜜色木地板，灶间和柴房夯土；院里都是暖土黄泥地 | | 屋子连成一座：共用墙、门洞相通，墙是抬高的奶油色断面加一截石灰墙面（第 10 节）；01、02 两张目标图还是一间间分开的旧画法 |

## 3. 颜色和光编码状态

调色板：描边 #4A3424，木框 #8A5A36，奶油 #FFF4DF，按钮暖黄 #FFE3B0，番茄红 #E5533C，天蓝 #4FB3E8，院墙外草地 #C4D696，没盖的地基 #F6ECD4。物件自己的颜色在暖黄、橙棕、草绿、天蓝、砖红里取，饱和度中等偏高。

| 状态 | 色调 / 光 | 不依赖颜色的提示 |
|---|---|---|
| 小人健康 / 生病 | 生病时人物褪掉一半颜色、偏灰绿 | 头顶一只冒热气的药碗，套在番茄红圆框里；底部条里病名和「虚弱」变成番茄红边的小胶囊；拆件动画里咳嗽、低头 |
| 干净 / 脏乱 | 地面不变色 | 脏乱是一摊摊没有描边的灰褐色堆，数得出几摊 |
| 白天 / 夜里 | 夜里整屋乘一层蓝紫（目标图用 0.58, 0.62, 0.82，比游戏现在的 `NIGHT_COLOR` 0.45, 0.5, 0.7 亮，暖色卡通压太暗会脏）；油灯、烛台、卧房灯各一团暖黄光 | 睡着的人旁边三个大小递增的「z」；界面不变暗 |
| 盖好的 / 没盖的屋子 | 盖好的有地面、墙和木框 | 没盖的是一块奶油色地基、一圈虚线，正中写屋名，下面一枚圆角小牌「加盖 600 文」 |
| 钱够 / 钱不够 | 钱不够的按钮变淡灰 | 按钮上的字从「买」换成「钱不够」 |

屋里的地面贴图在游戏里乘两成奶油色（`modulate`），院子乘两成半，人和家具才浮在地面上面。

## 4. 界面信息层级

- **常驻**：底部条 96 像素高，奶油底，顶上一道木色边，四角圆。从左到右：圆头像（番茄红圈）、名字和「岁数 · 营生等级」、在做什么和进度、身上状态（一个词一颗小胶囊）、铜钱图标和钱、存粮、五个圆角按钮（家谱、集市、账房、摆设、设置）。左上角两颗圆按钮：罚（木色）、赏（番茄红）。
- **按需**：集市、账房、家谱、设置，正中弹出，560 宽，木框圆角奶油底，房子上压一层半透明暗色。
- **瞬时**：屏幕上方正中的圆角提示条，左边一颗天蓝圆点，最多 4 条，3 秒消失；小人头顶的「赏」「罚」飘字。

界面风格契约：

| 项 | 定法 |
|---|---|
| 底色 | 奶油 #FFF4DF，不加纹理 |
| 边框 | 面板外一圈 8 像素木色 #8A5A36，圆角 22；里面奶油底圆角 16 |
| 按钮 | 暖黄底、2 像素深棕描边、圆角 12，底下一道 3 像素深色「厚度」；禁用时淡灰底、浅灰字，字换成原因 |
| 强调色 | 番茄红：选中、病、警告；天蓝：可捡的东西、提示条的圆点 |
| 字体 | 标题、名字、按钮、数字用站酷快乐体（ZCOOL KuaiLe），正文用思源黑体 Noto Sans SC。两款都是 SIL 开放字体许可 1.1，可以免费商用、随游戏打包；快乐体从 Google Fonts 官方仓库下载到 `.cache/`（不提交），正文沿用游戏已有的 Noto Sans SC。打包前照 README 的 `build_font.py` 只截取用到的字 |
| 图标 | 和素材同一画法的小图（药碗、铜钱），不用线性图标 |

## 5. 关键游戏时刻

### 时刻一：晌午院子（`design/targets/01_晌午院子.png`）
晌午，日头把院子的土晒成暖黄。镜头停在院子正中，程大柱拖着铁锹往前走，脚下一圈番茄红，头顶的名牌写着「拿铁锹铲掉院里的鸡粪」，进度条走到三成半。他脚边那堆枯叶没有一根描边，灰扑扑贴在地上，身后的石磨一圈深棕线，亮亮地立着。堂屋里柳晚晴就着门口的亮光缝衣裳，苏素纨弓着背挨在矮凳边。屏幕顶上冒出一条提示：捡到鸡窝外的鸡蛋，卖了 6 文。玩家的眼睛先落在番茄红圈上，再落到葡萄架旁那颗天蓝圆片：一串铜钱。左边两块奶油色地基挂着「加盖 600 文」「加盖 1200 文」的小牌。前一帧大柱刚在门槛上扒完饭，后一帧他弯腰铲土。玩家看一眼铜钱，再看底部条上的 200 文够不够盖西屋。

### 时刻二：夜里伤风（`design/targets/02_夜里伤风.png`，不开面板的是 `02b_夜里伤风_无面板.png`）
夜里，院子沉进一层蓝紫。堂屋油灯和供桌烛台各晕开一团暖黄，程大柱在灯下拨灯芯。卧房里柳晚晴咳得弓起背，脸色褪成灰绿，头顶一只冒热气的药碗套在番茄红圆框里；孩子在炕边，头顶飘着三个「z」。玩家点开集市：老姜红枣丸，治伤风，30 文。手头 26 文。按钮上三个字：钱不够。底部条上「伤风」「虚弱」两颗胶囊描着番茄红。前一帧她还在灯下缝补旧衣裳，后一帧玩家关掉面板，去账房翻还能卖什么。

这一幕最怕看错：病了的人、缺的钱、买不起的药要在一屏里同时认出来，分别靠药碗、底部条的数字、灰掉的按钮，没有一样只靠颜色。

## 6. 素材规格和角色动画

| 项 | 本作 |
|---|---|
| 视角 | 斜俯视。游戏的格子是 48×36（纵向压成四分之三），屋子后墙是一条 30 像素的墙带，物件画成从斜上方约 45 度看；地面贴图正俯视画，进游戏纵向压到 0.75 |
| 一格多大 | 1 倍缩放下 48×36；素材按 2 倍出（一格 96×72），游戏放大到 2 倍不糊 |
| 人物多高（1 倍） | 大人 90 像素（父亲 90，母亲 86），老人 74，孩子 62。现在白盒小人和点击框都是 28×44，接素材时点击框要放大到约 36×90，名牌位置跟着上移，这一步归游戏那边 |
| 头身比 | 大人约 1:4.5，老人背驼，孩子约 1:3。同一个画师的手：同样粗的描边、同样的圆眼睛和腮红 |
| 描边 | 1 倍缩放下外轮廓不细于 2 像素，深棕 #4A3424，粗细均匀 |
| 角色动画 | 骨骼拆件（`cutout-animation`，`rig.humanoid_side.json`）。每人 6 张图拼 10 个部件：头连脖子、躯干（肩到胯，衣服把肩头整个包住，不带胳膊）、上臂（整段袖子）、前臂连手、大腿、小腿连鞋；远侧胳膊腿复用近侧的图压暗。关节两头画圆头，大腿小腿一样粗 |
| 朝向 | 只画正侧面朝右，往左走根节点 `scale.x = -1` |
| 动作 | 走、待机用默认动作表；铲、扫、织、咳、睡往动作表里加行。睡觉要一个躺姿（目标图里孩子还站着睡，等这一行补上） |
| 背景 | 按材料出无缝贴图：院子泥土地、堂屋方砖、卧房木地板、灶间柴房夯土、屋里石灰墙；房间木框、墙梁、虚线地基、院墙外草地由代码画 |
| 物件 | 底边对齐占地格子下沿，宽不超过格子九成；影子由代码画 |

### 出图时学到的几条（已写进提示词和 `manifest.csv` 备注）
- 物件、脏乱、掉落物都用浅灰白底 #F0F0F0，人物和拆件用绿幕 #00FF00。
- 贴图四周常带一圈边框或纸边：处理前先裁掉四边 80 像素再跑 `make_seamless.py`。
- 模型爱往桌面上画一颗小星星，会和「可捡」的天蓝星搞混：提示词写明「不画闪光和小星星」。
- 鸡蛋的浅色高光会和背景一起被抠穿，留了一个小洞。下次换深一点的底色，或者让高光更深。
- 第一版一家人画成了小孩：提示词要写明「成年人头身比 1:5、下巴清楚、不要画成少年」，老人要写「背明显驼着向前弓」。
- 拆件图写「衣服把肩头整个包住」后，躯干上的肩口圆洞没了；「大腿小腿一样粗」让膝盖接缝基本平了。父亲的上臂比袖口略宽，抬手到很高时肘部能看出一点台阶。
- 生图服务要绕开本机代理：给 `NO_PROXY` 加上 `.volces.com`。

## 10. 连成一座房子：画法（给游戏代码照着做）

`design/targets/compose_house.py` 是这一节的样板实现，下面的数都从那里来。房间的位置是提议，`rooms.json` 现在的坐标还没改。

**格子。** 整张地图 56×32 格（一格仍是 48×36 像素），院墙里 34×19 格，院墙的左上角在地图的 (11, 6)。房间的大小沿用 `rooms.json`，只有三处为了拼得严：厢房 6×6、鸡舍 6×7、菜园 7×6。

| 位置（院墙内格子） | 房间 |
|---|---|
| 北排 y 0–6 | 柴房 (0,0) · 西屋 (6,0) · 堂屋 (12,0)，10 宽 · 卧房 (22,0) · 厢房 (28,0) |
| 西厢 x 0–6 | 灶间 (0,6) · 书房 (0,12)，6×7 |
| 东厢 x 28–34 | 鸡舍 (28,6)，6×7 · 猪圈 (28,13) |
| 当中 | 院子 (6,6)，17×7 · 井台 (23,6)，5×7 |
| 南排 y 13–19 | 晒场 (6,13) · 大门口 (13,13) · 菜园 (21,13) |
| 墙外 | 竹林在西，后山小路在北，河边在东（河宽 7 格，有一座木桥），田埂在西南，村口大树下在南；一条土路从大门往南，岔向田埂和大树 |

**墙不占格子。** 墙画在两间屋的分界线上，骑线居中，两边各占半个墙厚：
- 屋墙平面厚 12 像素（四分之一格宽）。东西走向的墙画两层：顶面（奶油色断面加深棕描边）往上抬 22 像素，下面露出 22 像素高的朝南墙面（石灰墙贴图）。南北走向的墙只画抬高的顶面，末端补一小块墙面。
- 院墙平面厚 16 像素，墙面 34 像素高，用夯土加石基的墙面贴图，顶上一道灰瓦檐。
- 两间屋共用一道墙，只画一次。屋子的外边落在院墙上时，不画屋墙，画院墙。
- 北墙的墙面会盖住这间屋第 0 行上面约 22 像素，所以第 0 行的家具（供桌、书案、土炕）靠墙站，看起来正好贴着墙。

**门。** 门是墙上空出来的一段：一般 1 格宽，堂屋正门 2 格宽，大门 2 格宽。东西墙上的门洞里放一条石门槛（素材 `a_door_sill`），南北墙上的门洞里画一块灰色窄门槛。门通向没盖的屋子时，那段墙不开口，等盖好再开。目标图里的门：堂屋正门、卧房南门、堂屋通卧房、柴房通灶间、灶间通院子。

**屋子的格子怎么变成地面和墙。** 一间屋的 w×h 格全部铺地面贴图（堂屋方砖、卧房和书房厢房木地板、灶间柴房夯土），墙从上面压过去。屋外的格子（院子、晒场、大门口、菜园、鸡舍、猪圈）共用一整片院子泥地，彼此之间不画墙；井台铺石板；从大门到堂屋正门铺一条 2 格宽的石板路。鸡舍朝院子那一边围一道竹篱笆，留 1 格口子。

**先后顺序。** 地面 → 墙（顶面和墙面）→ 门槛 → 家具、人、脏乱、掉落物按脚底的 y 从上往下画 → 屋名 → 名牌和界面。人站在墙南边时，身子会盖住墙面，这是对的。

**屋名。** 不再画框，写在地上：屋里的写在北墙脚下、离西墙 14 像素；院里的写在那块地的左下角。字用站酷快乐体，奶油色描边。

**没盖的屋。** 地上一块奶油色地基，四周一圈灰色石基，石基上一道虚线；正中写屋名和「加盖 600 文」的小牌。它自己不立墙，旁边盖好的屋子的墙照常立着。院里没盖的地方（晒场、菜园、猪圈）只在泥地上画一圈虚线和同样的小牌。

**立体感：做法 A「墙立起来」**（对比图 `design/targets/04_立体感对比.png`，样板 `design/targets/depth_walls.py`，用 `compose_house.render(tall=True)` 出图）。格子和墙的位置不变，只改墙怎么画：
- **后墙和前墙。** 一道东西走向的墙，南边紧挨着一间盖好的屋子时是后墙，否则是前墙。后墙露出 76 像素高的朝南墙面（约两行格子），从上到下：6 像素深棕梁线、石灰墙面、14 像素木色墙裙；顶上一条 12 像素厚的深色断面（#604A3A）。前墙切到只剩 18 像素高，站在屋里靠南边的人全身都看得见。
- **南北走向的墙。** 全高，断面抬起 76 像素，南端补一块 76 像素高的墙面。
- **屋檐。** 北排屋子的北墙顶上加一条 26 像素宽的瓦檐，从上往下看是灰蓝瓦垄，下沿一道深色，檐下往墙面投一条 14 像素的淡影。
- **太阳在西北。** 朝南的墙面乘 0.82 变暗。东西走向的后墙往南投 38 像素影子，前墙投 10 像素；南北走向的墙往东投 26 像素。影子是深棕色，墙脚处不透明度 0.38，往外线性淡到 0，再模糊 3 像素。
- **墙脚暗边。** 南北墙的西侧加 9 像素、不透明度 0.20 的暗边；家具底下的影子放大到物件宽度的 95%。
- **门。** 后墙上的门洞留出上面 24 像素作门楣（下沿一道深棕横梁，两边各一根 6 像素门框），门洞里看到的是后面那间屋的地面，压暗到 55%。南北墙上的门，断面照常连过去当门楣，门洞处地面压暗。前墙上的门还是空一段加石门槛。
- **透视规则。** 前墙一律切低，所以人和家具不会被前墙挡住；后墙和南北墙按脚底的 y 和人一起排序，人站在墙南边时盖在墙面前面。
- 做法 B（斜 45° 菱形格子）只拼了草样，要走这条路，地面、墙、家具都得按新角度重画，格子坐标也要换。

**缩放。** 不做缩放（2026-11-25 定，照 Virtual Families）：大房子固定按 1.1 倍显示，拖地面平移，点人镜头跟着走。一屏看不全院子，靠平移和跟人。
