# 界面方案 · 起家

玩家打开游戏，眼睛先落在两处：左上角「有事找你」的一叠小卡，底部条上选中的那个人此刻怎么样。说亲、门口的猫狗、没拆的信、病了的人，都在左上角写成一句话，点一下就打开要回话的那张卡。家谱按钮上那颗小圆点去掉了。

做法照 ai-rpg-studio 的 ui-layout（先列玩家要做的决定，再排界面）和 `design/ART_DIRECTION.md` 第 4 节的界面风格契约：奶油底、木色框、深棕字 #4A3424，番茄红 #E5533C 只给「出了事、要你定」，天蓝 #4FB3E8 只给「地上有东西可捡」。

## 原来的界面哪里看不懂

对照 `~/Downloads/qijia_house_shots/` 里 iso2_hall.png、letter_proposal.png、fix_hall.png 逐件看过：

| 部件 | 原来 | 毛病 |
|---|---|---|
| 底部条，选中的人 | 一块纯色方块、名字、岁数营生、在做什么、四个状态词连成一串（「吃饱了、抖擞、舒心、康健」） | 状态词一样大一样颜色，饿了和吃饱了长得一样；方块看不出是谁 |
| 钱、存粮、季节天气 | 三行字挤在按钮左边 | 没有图标，和状态词混在一起 |
| 家谱 / 集市 / 账房 / 旧物匣 / 摆设 / 设置 | 六个一样大的文字按钮 | 天天用的和一周点一次的一样大 |
| 信匣 | 右上角单独一个按钮 | 离别的按钮很远，像是另一套界面 |
| 罚 / 赏 | 左上角两颗圆钮 | 离选中的人很远，看不出在罚谁赏谁 |
| 说亲、门口来了猫狗 | 家谱按钮上一颗「●」 | 玩家不知道圆点是什么，更想不到去家谱里找说亲 |
| 信 | 墙头的鸽子和「信匣（2）」 | 鸽子要找，回过一半的信没人提醒 |
| 生病 | 一条三秒的提示条 | 错过就没了 |
| 卡片和面板 | 深灰底、白字、系统默认按钮 | 和奶油色的底部条、暖色的房子像两款游戏 |
| 收留 | 一张只有文字的卡，一次一个人 | 看不到人长什么样，只能换一位再换一位 |
| 集市 | 一长串货，分类标题夹在中间 | 东西一多就翻不到 |

## 信息分三层

**一眼看到（常驻，不点）**
- 左上角「有事找你 · n」：等你回话、等你处理的事，每件一张小卡。
- 底部条：选中的人此刻怎么样；身上不对劲的地方；家里的钱、存粮、季节天气；主按钮。
- 屏幕上方正中：刚发生的事，一条提示条，三秒消失。

**点一下（卡片，正中弹出，盖住房子）**
- 说亲、门口的动物、信纸、添丁、亲戚上门、旧物、离开期间、收留挑人。卡片只做一件事：看完、回话、关掉。

**面板（按钮打开，看和挑）**
- 家谱、集市、账房、旧物匣、信匣、设置、摆设。面板打开时房子不接收点击，Esc 关。

## 「有事找你」

左上角一叠小卡，宽 300，每张一行：左边一个画出来的小图标，中间一句话，右边一个「›」。左边框的颜色分事：番茄红是要你定或有人不好，天蓝是地上有东西，木色是不急的。最多摆 5 张，多出来的写「还有 n 件」。什么都没有时整叠收起来。

| 事 | 角上写 | 点了 | 什么时候消失 |
|---|---|---|---|
| 说亲 | 「王媒婆来给砚之说亲」（媒人的信到了用写信人的名字，没信就写「媒人来给砚之说亲」） | 说亲卡：对方的画像、岁数营生、喜好、带来多少钱，应下 / 回绝 | 回了话或过期 |
| 门口来了动物 | 「门口来了只狸花猫，等你发话」 | 门口卡：收留 / 撵走 | 回了话或它走了 |
| 没拆的信 | 「表舅来信，还没拆」 | 那封信 | 拆开 |
| 拆了没回的信 | 「表舅来信，等你回话」 | 那封信，选项在纸上 | 回了话，或信上的事已经过去 |
| 信太多 | 两封以上收成一张「信匣里还有 n 封信」 | 信匣 | 都拆了、回了 |
| 病了 | 「沈砚之看着不大对劲」 | 选中他，镜头跟过去 | 病好或人走了 |
| 身上到了最差一档 | 「沈砚之饿得心慌」 | 选中他 | 那一档过去 |
| 动物病了 | 「大黄看着不大对劲」 | 选中它 | 病好 |
| 动物跑了 | 「大黄跑出去了，还没回来」 | 家谱，动物那一栏 | 回来或再没回来 |
| 如愿了在谢你 | 「砚之如愿了，正谢你呢」 | 选中他，看他挥手 | 谢完 |
| 地上有东西 | 「灶间地上有东西在闪」（三样以上收成一张） | 镜头移到那儿 | 捡走或消失 |
| 心愿 | 「砚之想看本话本」（只列玩家办得到的：买、摆、盖、养、夸） | 选中他；要买的东西顺手打开集市 | 如愿或过期 |

排序：要你定的（说亲、门口、信）在最上，其次是人和动物出事，再是谢你、捡东西、心愿。

添丁、亲戚上门、捡到旧物、旧事收尾的访客照旧自己弹卡：这些只需要看一眼，弹出来就不会错过。

代码在 `game/kernel/view/notices.gd`（只读 World，不读病名；谁病了由界面看到的 fell_ill / cured 事件记下），点了以后去哪由 `Main.open_notice` 决定。

## 底部条

高 96，从左到右：

1. **画像**：番茄红圈里一枚圆，填这人的颜色，写名字的头一个字。
2. **此刻怎么样**（19 号字，最大的一行）：现在写「在做：拿抹布擦一遍饭桌」，人被拖去干活就跟着变。player-loop 分支要加一句「此刻的感受」，接口是 `Hud.feeling_now(p)`，到时只改这一个函数。下面一行 16 号字写名字，13 号淡色字写「34 岁 · 佃户 · 学徒」；有心愿再一行木色小字「心愿：想看本话本」。
3. **赏 / 罚**：两颗圆钮挨着这个人，没选人时灰掉。
4. **身上不对劲的**：最多四颗小胶囊，最差一档番茄红实底白字，偏低的番茄红描边，怀着身孕木色描边。都还行时只写一行淡色的「身上都好」，「吃饱了」「抖擞」这类好词不再占地方。胶囊里带需要的名字（「饱腹 饿得心慌」），玩家知道是哪一样。
5. **家里**：季节天气（小太阳）、钱（铜钱，20 号字）、存粮（米碗）。
6. **按钮**：上排三个大的带图标，家谱、集市、信匣（有信时写「信匣（2）」）；下排四个小的，账房、旧物匣、摆设、设置。

字号在 1280×720 下：此刻怎么样 19，钱 20，大按钮 17，名字 16，胶囊 15，提示条 16，小按钮 14，岁数营生 13。

## 卡片和面板

全部换成界面风格契约那一套：奶油底，6 像素木色框，圆角 18，底下一层淡影；字深棕；按钮暖黄、深棕描边、下边一道厚度。房子上压一层偏棕的半透明暗色。集市里买不起的按钮字从「买」换成「钱不够」，按钮变灰。

**收留挑人**：开局和重新收留时，一排并列三张卡，每张一个人：画像、名字、「男 · 24 岁」、「营生：佃户 · 学徒」、喜欢、厌恶，下面一个「收留」。底下一个「换一批」。画像按顺序取：这人自己那套长相的画像（`PersonPortrait.portrait`，先问皮肤的 `look_portrait(id)`，main 上正在接；没有这个接口时找美术目录里的 `chars/portraits/<id>.png`），没有画像就画他的拆件正面图，站着轻轻呼吸，再没有就是一枚写着名字头一个字的色块。三个人由内核给（`World.candidates`，命令 `adopt` 带 `pick`）；多出来的两个用另一颗骰子摇，世界的骰子和原来一样走。存档不存这两个，读档后只剩原来那一个，点「换一批」又是三个。

**说亲卡**：对方的画像放在左边，右边是名字、岁数、营生、喜好；下面写带来多少钱。

**集市**：顶上一排分栏，食物与药 / 二手市场 / 营生 / 房屋 / 衣裳 / 宠物 / 升级与服务，最后是「家里存的」。栏名和哪类货进哪栏写在主题包的 `ui.json`（`market.tabs`、`market.cat.<货的类>`）。market 分支的内核货单到了以后，改 `Panels._market_tabs` 这一个函数从货单建栏。眼下二手市场、升级与服务还没有货，写一句「这几样还没上市」；房屋一栏指去摆设。没配栏名的主题包，每一类货自成一栏。

**提示条**：屏幕上方正中，奶油底、深棕描边、左边一颗天蓝圆点，最多四条，三秒。有人挣了钱来报喜（player-loop 分支的「今天挣了 30 文！」），走 `Hud.earned(人, 话)`：话从那人头顶飘起来，上方一条金黄底、铜钱图标的提示条，停四秒半。

## 留给别的分支的接口

| 接口 | 现在 | 谁来接 |
|---|---|---|
| `Hud.feeling_now(p)` | 写「在做：…」 | player-loop 的「此刻的感受」 |
| `Hud.earned(uid, text)` | 已能用，等调用 | player-loop 的挣钱报喜 |
| `Panels._market_tabs(w)` | 按 ui.json 把今天的货分栏 | market 的分类货单和服务 |
| `PersonPortrait.portrait()` | 候选人字典里有 `look` 就找画像，找不到退回拆件 | main 上的长相：Person 的 `look`、皮肤的 `look_portrait(id)` |
