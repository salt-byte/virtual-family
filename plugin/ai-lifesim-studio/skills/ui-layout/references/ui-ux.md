## 包含什么

| 产出 | 必填内容 | 手册中的真实作品参照 |
|---|---|---|
| 界面清单 | 底部条、商店面板、目标与收集、家谱、家具摆放、设置等，按高频、中频、低频分级 | 按使用频率分级，高频界面优先打磨 |
| HUD 设计 | 平时屏幕上常驻哪些信息 | 《只狼》只留血条、架势条和忍具，信息一目了然 |
| 信息层级 | 每个界面最重要的信息是什么、放哪、怎么突出 | 《暗黑破坏神》用颜色区分装备品质，一眼看出值不值得捡 |
| 交互流程 | 常用操作的步骤 | 《原神》强化装备：选装备、选材料、确认，三步完成 |
| 操作动线 | 界面之间怎样跳转 | 《女神异闻录5》用转场动画连接各界面，跳转本身成为体验 |
| 反馈提示 | 成功、失败、获得、解锁时的反馈规范 | 《原神》抽到五星角色时的金光特效和专属音效 |
| 新手引导 UI | 教学怎样嵌进界面和关卡 | 《塞尔达传说：旷野之息》几乎没有文字教程，用关卡隐性引导 |
| 适配与可读性 | 平台、输入方式、字号与文本量 | 《原神》支持手柄、触屏、键鼠三套操作，界面自动适配 |

以上案例来自手册，引用具体界面时核对作品资料。

## 怎么写 · 三步

1. 列界面清单并分级。按高频、中频、低频分级，高频界面（HUD、背包、对话框）优先打磨。先写玩家在这个界面要做的决定，再画界面。
2. 画关键操作动线。挑 3–5 个最常做的操作，画出每一步点击，尽量压到 3 步以内。
3. 定信息层级与反馈规范。写明每个界面最重要的信息是什么、放哪、怎么突出；统一成功、失败、获得、解锁的反馈。

## 产出示例 · 剧情选择界面<!-- TODO(lifesim): 原文是 RPG 的剧情选择界面，生活模拟游戏没有剧情选择，待换成本项目的例子 -->

关键抉择用全屏演出、两个选项加倒计时：选项文案用原作语气，倒计时制造紧迫感，选择后立刻给视觉反馈（屏幕色调变化），让玩家感到这个选择有分量。倒计时是否适合本作的节奏，在原型或试玩中验证。

## 品类要点<!-- TODO(lifesim): 以下三条是改编 RPG 的品类要点（剧情、对话历史、图鉴连着叙事），本项目没有，待改写 -->

- 剧情界面要沉浸。对话框和选择界面贴合原作氛围（古风可用水墨风），不用破坏代入的通用模板。
- 大量文本要可读。改编 RPG 文本量大，重点设计剧情回顾、对话历史、自动播放、快进和跳过。
- 图鉴可以连着叙事。图鉴做成原作设定集，玩家收集时就在阅读世界观，内容取自世界观圣经。
