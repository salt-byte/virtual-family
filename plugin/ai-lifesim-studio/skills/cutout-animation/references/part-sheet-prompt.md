# 拆件图提示词

拆件图 = 同一个角色拆成几块，按格子排在一张绿幕上。配 `rig.humanoid_side.json` 的是 6 块、3 行 2 列；远侧的胳膊和腿复用近侧的图，不用单独画。

## 先有一张站立参考图
拆件图之前先生一张角色的侧面站立图（朝右、全身、绿幕），用户确认长相以后，拆件图附上它当参考图。没有参考图直接生拆件图，每块都会像不同的人。

## 模板
```
〈风格线〉
把参考图里的这个角色拆成 6 个部件，画在一张图上，排成 3 行 2 列的格子，每格一个部件，居中，部件之间留出大片空白，互相不接触。
所有部件都是侧面朝右，和参考图同一个角色：脸、发型、衣服、颜色、线条粗细一模一样。
第 1 行：左格是头连脖子（脖子往下多画一截）；右格是躯干，从肩到胯，不带胳膊和腿。
第 2 行：左格是上臂，竖直朝下；右格是前臂连手，竖直朝下。
第 3 行：左格是大腿，竖直朝下；右格是小腿连脚，竖直朝下，脚尖朝右。
胳膊和腿的两头都画成圆头（像关节处的圆球），圆头的直径和那一段一样宽；关节处多画一截，不要画成平切口。
背景是一整片纯绿色 #00FF00，没有渐变、没有阴影、没有地面、没有文字。
部件上不用纯绿色。
```

## 为什么这样要求
| 要求 | 不这样会怎样 |
|---|---|
| 3 行 2 列、一格一个 | `split_parts.py` 按格子认部件；排乱了要手动 `--map` |
| 两头画成圆头 | 关节点在圆头的圆心上，转到 30° 以上时平切口会露出一道缝 |
| 脖子多画一截 | 头低下、抬起时脖子根露出来 |
| 竖直朝下 | 站立姿势就是 0°，动作表里的角度才对得上 |
| 不带胳膊的躯干 | 躯干上画了胳膊，拆出来的胳膊动了，身上还留着一条不动的 |

## 自己上传的部件
用户在自己的软件里分好了部件，按部件 id 命名放进一个目录（`head.png`、`torso.png`、`arm_upper.png`、`arm_lower.png`、`leg_upper.png`、`leg_lower.png`），透明背景或纯色底都行，用 `split_parts.py --from-dir`。要求和上面一样：侧面朝右、竖直朝下、关节画圆头。

## 别的身形
四足动物、带翅膀的、拿长工具的：复制 `rig.humanoid_side.json` 改一份。每个部件写 `parent`（挂在谁身上）、`z`（前后）、`pivot`（自己绕哪一点转）、`attach`（挂在父部件图上哪一点）；`sheet_rows` 写拆件图上每格放哪块，提示词照着 `sheet_rows` 写。动作表照 `anims.humanoid_side.json` 的格式另写一份。
