# 生图提示词：让脚本切得开

提示词写进 `assets/gen/prompts.json` 的 `prompt`，由 `gen_image.py` 发给生图服务（退回手动时 `--export-md` 导出给用户）。每条三段：**风格线**（第 1 步定的那段，原样贴）+ **内容** + **出图要求**。前两段管好不好看，第三段管脚本能不能直接处理。出图要求照下面的模板写，按这一张的情况改括号里的值。

Seedream、OpenAI、Gemini 都听得懂中文，用中文写；本机的 Stable Diffusion 对英文更听话，把整条译成英文（它不读长句，写成逗号隔开的短语）。
服务能直接出透明底、`gen_config.json` 开了 `native_transparent` 时，`background` 写 `"transparent"`，下面模板里「背景是……」那句换成「透明背景」。

## 物件合集（一次出 4–8 个）
```
〈风格线〉
画一张素材合集：〈N〉列 × 〈M〉行的格子，一格放一个物件，物件在格子里居中，互相不接触，每个物件四周留出至少物件宽度五分之一的空白。
第 1 行从左到右：〈rock_moss：长青苔的灰石头〉、〈tree_ash：白蜡树，叶子稀〉、……
第 2 行从左到右：……
背景是一整片均匀的浅灰色 #F0F0F0，没有渐变、没有纹理、没有格线。
物件不带投影、不带地面、不带文字和边框；每个物件完整画在格子里，不被画面边缘切掉。
所有物件光从〈左上〉来，视角〈俯视 45°〉，大小比例按真实大小。
```
`prompts.json` 这条写 `"grid": "〈N〉x〈M〉"`、`"background": "#F0F0F0"`；`process_inbox.py` 会跑 `split_objects.py --grid 〈N〉x〈M〉 --key --manifest … --batch <合集名>`。
物件本身是浅灰或白色（石膏像、雪人）时，背景改成深色 #202020 或品红 #FF00FF。

## 角色站立图、单张物件
```
〈风格线〉
画〈内容〉，全身，〈朝向：正面 / 侧面朝右〉，站在画面正中，四周留空。
背景是一整片纯绿色 #00FF00（绿幕），没有渐变、没有阴影、没有地面。
角色身上不用纯绿色。
```
角色身上必须有绿色时，背景改成品红 #FF00FF，提示词里写「角色身上不用品红」。
`background` 写 `"#00FF00"`（或品红）；`process_inbox.py` 按这个颜色跑 `remove_bg.py`。

## 地块、墙面（要平铺的）
```
〈风格线〉
画一块正方形的〈踩实的雪地，带车辙〉纹理，俯视，铺满整个画面，没有边框。
光照均匀，画面四个角和中间一样亮，没有暗角、没有光斑。
纹理里的细节大小均匀，不要一块特别显眼的东西（一块大石头、一朵花），那种东西单独做成物件。
```
清单 `type` 写 `tile`；`process_inbox.py` 跑 `make_seamless.py`（像素风在 `gen_config.json` 写 `pixel_size`）。看 `_preview.png`：还能看出一块一块的，就是纹理里有显眼的东西，改提示词。

## 整张帧表（像素风或卡通的逐帧动画）
```
〈风格线〉
画同一个角色的行走帧：4 行 × 3 列。第 1 行朝下，第 2 行朝左，第 3 行朝右，第 4 行朝上；每行从左到右是迈左脚、站直、迈右脚。
每一格里角色一样大、脚底在同一高度、居中；格子之间留空，角色互不接触。
附上的参考图就是这个角色，脸、发型、衣服、颜色和参考图一模一样。
背景是一整片纯绿色 #00FF00。
```
`refs` 带上 `assets/gen/ref/hero_ref.png`，`grid` 写 `"3x4"`，清单 `type` 写 `frames`；收图后逐帧和参考图比。

## 常见的坑
| 现象 | 原因 | 改提示词 |
|---|---|---|
| `remove_bg.py` 说几乎没抠掉 | 背景有渐变或纹理 | 强调「一整片均匀的纯色，没有渐变」；换一个工具常用的纯色（纯白、纯绿） |
| 物体里有一块被抠成透明 | 物体颜色和背景太接近 | 换反差大的背景色 |
| `split_objects.py` 说一格两个、有空格 | 没按格子排，或两个物件挨着 | 写明列数行数，「互相不接触，四周留空」 |
| 一个物件被切成两半 | 物件本身是断开的（栅栏的几根木条） | 切的时候调大 `--merge-gap`；或提示词要求「画成连在一起的一整段」 |
| 物件下面带一团黑影 | 工具默认加投影 | 「不带投影、不带地面」写在最后一句再重复一次 |
| 平铺后一块亮一块暗 | 纹理带光照 | 「光照均匀，没有暗角」；`make_seamless.py` 默认会抹平明暗 |
