# 主题包验收（pack-verification）

四样都过了才交给用户，过程中守住第 5 节：不在用户屏幕上弹窗。哪样没过，要么改到过，要么停下来把最好的数字和原因告诉用户，不能悄悄放宽标准。

## 1. 测试

```
./game/tests/run.sh            # 全部，约 3 分钟
./game/tests/run.sh places     # 按文件名过滤，迭代时用
```

- 输出里出现 ERROR / WARNING 行、或某条测试一个断言都没做，都算失败。
- `_smoke` 是测试专用包：任何改动都不能改变它的行为，跑它的测试的预期一条都不能动。新字段的默认值必须等于改动前的行为。
- 要改已有测试的预期，逐条写下原因（通常是房子的几何变了、开局房间数变了）。
- 另外跑一下 `cd game && godot --headless --quit-after 5`，输出要干净。注意它会启动主场景、读玩家真实的存档（`user://save_<id>.json`）；跑之前看一眼存档的修改时间，跑完确认没被改写。更省事的是前面加 `HOME=<临时目录>`，`user://` 就落到那个目录下（macOS 上实测可行），碰不到真存档。

## 2. 平衡

```
cd game && godot --headless -s res://tools/balance_cli.gd -- qijia 20 3
```

20 户人家、各过 3 天。《起家》的验收线：

| 项 | 线 |
|---|---|
| `alive_at_end` | 全部活着 |
| `deaths_neglect` | 0 |
| `median_money` | 上一轮中位数的 0.7–1.5 倍（上一轮是 1262） |
| `food_bought_per_day` / `max_food_bought_in_a_day` | ≤ 2 |
| `avg_level` | ≥ 0.6（大人在升级，说明正事没被消遣挤掉） |

只调包里的数据去达标，别为了过线改内核。

## 3. 日记抽查

```
cd game && godot --headless -s res://tools/diary_cli.gd -- qijia 1 7
```

挑一个人，看白天十分钟和傍晚十分钟。要看到：换着做不同的事、事和地方对得上（院子里看星星，不在卧房里）、夜里大多在睡觉。`test_qijia_lone_adult_daytime_hour_is_varied` 要求一个独居大人白天一小时里至少 15 种不同的事。

## 4. 性能

```
./game/tests/run.sh perf
```

离线 48 小时的补算，上限 10 秒，四口人一条、四口人加两只动物一条。玩家关了游戏再打开，就要等这么久。量的时候电脑忙不忙会影响结果，报数时要写上负载。

**这 10 秒是所有功能合用的一笔预算**。每加一样东西（动作、生育、天气、宠物），每一步挑动作都多一点活，账记在同一个数上：

| 时候 | 48 小时补算 | 怎么来的 |
|---|---|---|
| 动作从 96 条加到 144 条 | 17 秒 | 候选扫描改成先跑便宜的是非判断、边扫边留前几名，降到 9.9 |
| 加了生育 | 10.0 秒，贴着上限 | 孕妇和照看婴儿的筛选放进按年龄段缓存的动作表，婴儿每步只列一次（ac400ba） |
| 挑动作提速（d066994） | 8.2 秒左右（提交里记 8.1，负载约 4） | 只跟性格、时辰、盖了哪些屋有关的判断按包缓存，物件按类型索引一次 |
| 季节天气、宠物进来 | 9.5 秒 | 天气给每个动作多乘几个系数，宠物每步挑自己的动作 |

规矩：

- 加功能之前先量一次，加完再量，把这一行记进提交说明。
- 提速不许改结果：同一个种子，补算 2 小时的摘要和 20×3 平衡的 JSON 要和提速前逐字节相同。
- 剩下的余量很薄。下一个功能吃过了 10 秒，先在这个功能自己身上省（缓存、跳过够不着候选池的动作、不需要的随机数不抽），省不下来再停下来问用户。

## 5. Godot 不许在用户屏幕上弹窗

用户在用这台电脑。验收时 Godot 每弹一次窗口，就抢一次焦点、挡一次用户的活。

- 测试、平衡、日记、宠物模拟、导入、主场景检查，全部带 `--headless`。`run.sh` 已经带了；手敲的命令自己加上。
- 截图要真渲染，`--headless` 截不了。全部截图攒到最后，用**一次**不带 `--headless` 的运行截完，窗口放到屏幕外：`--position 20000,20000`。别每改一处截一次。
- 截图那次用自己的 `user://` 目录，比如 `HOME=<临时目录> godot --position 20000,20000 ...`（macOS 上 `user://` 跟着 `HOME` 走），不读也不改玩家真实的存档。
- 截完把图发给用户看，不要求用户自己开窗口。

## 交给用户时说什么

- 全部测试的条数和结果，平衡那几项的数字，性能数字。
- 哪些只在测试里验证过、没在真窗口里看过（手感、画面、文字读起来对不对味），请用户亲眼看。
- 用户能直接点开的试玩方式：本地 `python3 -m http.server -d build/web 8060`，或发布后的网页链接（见 `web-release`）。
