# 行为表编排（action-authoring）

## 一条动作长什么样

```json
{"id": "study", "label": "伏在书案上摇头晃脑地念书", "kind": "daily", "duration_min": 30, "object": "desk",
 "base": 14, "needs": {"energy": -3}, "work": {"track": "reading"}, "hours": [7, 19],
 "tags": ["书痴"], "stages": ["adult", "elder"]}
{"id": "pace_and_mutter", "label": "背着手踱步自言自语", "kind": "flavor", "duration_min": 12,
 "rooms": ["hall", "yard", "study"], "base": 4, "tags": ["书痴"], "stages": ["adult", "elder"]}
```

| 字段 | 意思 |
|---|---|
| `kind` | `daily`：会改变需求（吃、睡、洗、干活）；`flavor`：纯消遣，`base > 0`，不写 `needs`、不写 `requires`（测试强制）；`trouble`：生病、脏乱这类，必须有触发条件（`sick` / `illness` / `need_below`） |
| `object` / `rooms` | 二选一。`object` 是用哪件家具或固定物件，小人走到它跟前做；`rooms` 是在哪几处做，小人走到其中一处已盖好的地方，随便找一格站着。两个都不写，就在当时所在的屋里做。只写了没盖的房间时做不了（`no_place`） |
| `work` | `{"track": <营生 id>}`，表示这是某一行的活，只有干这一行的人做，做完给工钱、长进度 |
| `hours` | `[开始, 结束]` 时辰。看星星放夜里，晾衣裳放白天 |
| `stages` | `child` / `adult` / `elder` |
| `tags` | 和人的性格词对上的会多做（《起家》：书痴、喜静、嘴馋、好侍弄、爱热闹） |
| `duration_min` | 走快钟；标了 `slow` 的走真实时间（睡觉这类） |

## 动作名怎么写

看现有的一百多条，照这个味道写：

- **身体在做的具体动作**，4–12 个字：「趴在井沿看自己的倒影」「把西瓜吊进井里镇凉」「蹲着用草棍逗蚂蚁」。
- 不写感受、不写抽象词：不要「享受宁静」「感到满足」「思考人生」。
- 不用现代词，和已有的不重意思（测试查长度和重名，意思重复要靠人看）。
- 写完逐条念一遍：念起来像在看一个人，就对了；像在读说明书，就重写。

## 「不干活」的事要有

玩家要的是小人在过日子，不是一直在干活。《起家》144 条里，`flavor` 占大半，其中专门有一批发呆类：托着腮望着天上的云发呆、靠着门框出神、盯着灶膛里的火苗发呆、看两只公鸡斗架。这类动作要**绑在合适的地方和时辰**：看星星、听蛐蛐放院子和大门口的夜里，晒太阳放墙根的白天。不绑地方，就会出现「在卧房里数星星」。

## 配给地方

- 每样固定物件配两三件事（井：打水、看倒影、坐井台歇脚）。
- 每处地方用 `rooms` 再配几件不靠物件的事。
- 开局盖好的每处至少 3 件，后盖的每处至少 2 件（`places-and-props` 第 5 步，有测试）。
- 原来不写地方的旧动作，挨个补上 `rooms`；扫地、捡东西这类走向目标的不补；能落到某样固定物件上的改成 `object`（上香 → 供桌，劈柴 → 柴垛）。

## 动作多了以后调这几个参数

都在 `pack.json`：

| 参数 | 《起家》的值 | 作用 |
|---|---|---|
| `choice_pool` | 10 | 每次从得分最高的这么多条里随机挑一条。太小会老做那几样，太大会乱做 |
| `repeat_memory` | 8 | 记住最近做过的几样 |
| `repeat_factor` | 0.1 | 最近做过的，分数乘这个数，压住重复 |
| `action_speed` | 30 | 快钟倍数：念一次书约 2 分钟、扫地约 30 秒，不开快进也看得见小人在换事 |
| `step_seconds` | 5 | 模拟一步的长度 |

加动作会稀释「正事」：动作从 96 条加到 144 条时，要确认大人还念得够书、家里还吃得饱。这些靠 `pack-verification` 的平衡跑来量，只改包里的数据，不改内核。

## 做完

1. `python3 game/tools/build_font.py`：新字要进网页版字体，否则网页上是方块。它会列出缺的字，必须一个都不缺。
2. 走一遍 `pack-verification`。
3. 把新加的动作名列给用户看，用户觉得不对味的直接改。
