# 季节、天气、饭菜和脏乱（seasons-and-weather）

日子要有个变化。春天小雨多、菜长得快；夏天雷阵雨，傍晚一家人摇着蒲扇乘凉；秋天在晒场翻谷；冬天下雪，孩子堆雪人，大人围着灶烤手。天气改的是小人想做什么，也改家里脏成什么样；饭菜和碗筷把「吃饭」和「收拾」接成一件事；打扫干净给钱，玩家就有理由去管那一地泥脚印。

## 季节和天气

`pack.json` 里的 `seasons` 块，空或不写就没有（`_smoke` 不变）。《起家》节选：

```json
"seasons": {"change_min": 15, "persist": 0.4, "dry_hours": 1.5, "wet_messes": {"mud": 30},
  "weather": [
    {"id": "clear", "name": "晴"},
    {"id": "drizzle", "name": "小雨", "wet": true, "outdoor": 0.35, "outside": 0.2,
     "view": {"kind": "rain", "amount": 0.45, "color": "#C9D6E2", "tint": "#7C88982E"}},
    {"id": "snowfall", "name": "下雪", "outdoor": 0.7, "outside": 0.3, "messes": {"snow_cover": 50},
     "view": {"kind": "snow", "amount": 0.7, "color": "#FFFFFF", "tint": "#DDE6F022"}}],
  "list": [
    {"id": "spring", "name": "春", "weather": {"clear": 3, "drizzle": 5, "overcast": 2},
     "boost": {"garden": 1.8, "water_garden": 1.5}, "yields": {"greens": 2}},
    {"id": "autumn", "name": "秋", "weather": {"clear": 8, "overcast": 2, "drizzle": 1},
     "boost": {"turn_grain": 3, "flail_grain": 1.5, "chew_straw": 2}, "messes": {"leaves": 40}}]}
```

- **季节只看钟**：一年（`hours_per_year`，《起家》4 小时）平分给 `list` 里的几季，一季 1 小时。
- **天气每 `change_min` 分钟掷一次**，《起家》15 分钟：40%（`persist`）留着原来的，否则按这一季的 `weather` 权重重抽。一个时段只掷一次，所以离线补算掷出来的天气和一直开着玩一模一样。
- **天气压低出门的分**：`outdoor` 乘在院里做的事上，`outside` 乘在院墙外做的事上。小雨 0.35 / 0.2，雷阵雨 0.12 / 0.05。干活不受影响，专为这种天气写的事也不受影响。
- **`boost`**：季节和天气按动作 id、物件类型或标签乘一个系数。冬天灶 1.5、炕 1.3、烧炕 3，乘凉和河边泡脚压到 0.1 和 0.05；雷阵雨炕 1.5。
- **`yields`**：季节乘在动作的产出上。春天菜园摘菜翻倍，冬天是 0。
- **地湿**：`wet` 的天气里和停了以后 `dry_hours`（1.5 小时）内算地湿，`not_wet` 的动作（浇菜园）这时不做，`wet_messes` 每天冒 30 处泥脚印。

动作上加 `"weather": [...]` 或 `"seasons": [...]` 就只在那时做：

```json
{"id": "watch_rain_under_eaves", "label": "搬个小凳坐在屋檐下看雨", "kind": "flavor", "duration_min": 15,
 "rooms": ["hall", "bedroom", "west_room", "side"], "base": 4, "weather": ["drizzle", "thunderstorm"], "tags": ["喜静"]}
```

《起家》雨天有看雨、接雨水、冒雨收衣裳、听见打雷钻被窝、光脚踩水坑；雪天有堆雪人、接雪花；冬天烤手、挤在热炕头唠嗑；夏天傍晚乘凉。

天气的 `view` 是给界面的：`rain` 或 `snow`、多密、什么颜色、整屏蒙一层什么色。界面上写着当下的季节和天气。

## 脏乱跟着天和季走

`messes.json` 里的一种脏乱可以不靠每天随机冒（`spawn_per_day: 0`），只靠季节、天气、地湿或某个动作带出来：

```json
{"id": "snow_cover", "name": "积雪", "spawn_per_day": 0, "outdoor": true, "penalty": {"happy": 0.2},
 "color": "#F4F7FA", "look": "patch", "seasons": ["winter"]}
```

写了 `seasons` 的那种，换季就自己没了（雪化了、落叶烂了），不算谁打扫的。《起家》现在七种：碎屑、鸡粪、碗筷（吃完饭剩的）、泥脚印（雨后）、积雪（下雪）、落叶（秋冬）、狗毛（宠物，见 `pets`）。院墙外的地方（`outside`）不冒脏乱。

## 饭菜

`dishes.json`：

```json
{"id": "porridge", "name": "一锅热粥", "portions": 3, "on": ["dining_table", "stove"],
 "leaves": "bowls", "scraps": "scraps", "ttl_hours": 5, "color": "#F3E9CF"}
```

- 带 `"serves": "porridge"` 的动作（蹲在灶前烧火熬粥）做完，粥摆到 `on` 里第一种有的物件上：有饭桌摆饭桌，没有就搁灶台。同一种一次只摆一锅（`max_out`，默认 1）。
- 带 `"eats": ["porridge"]` 的动作把人叫到桌边，一人一份。有几份就最多几个人去。
- 最后一份吃完，或者放过了 `ttl_hours` 没人吃，原地留下 `leaves` 那种脏乱（没收的碗筷），`scraps` 那样存货加一（剩饭，狗和猫吃它）。
- 动作还能带 `yields` 往存货里加东西：菜园摘菜给 `greens`，炒青菜就用它。
- 玩家把人拖到摆着饭的桌上，他就坐下吃。

热饭（喝粥加 50 饱、炒青菜加 25 饱，各带一点心情）比蹲门槛扒冷饭好，冷饭不用开火，照样能吃。两盘饭菜搁一张桌上时名字会叠在一起，所以桌上的碗只画每份一个圆点，不写字，颜色已经分得开。

## 打扫有钱拿

`pack.json`：

```json
"clean_reward": {"amount": 15}
```

最后一处脏乱被扫掉那一刻，全家得 15 文，一天（按玩家所在地的日子算）最多一次。钱从扫地那人头上飘起来，弹一行字说为什么。小人自己扫的也算。

## 设计的教训

1. **天气要让人看得出来**。只在数值上压低出门的分，玩家看不见；要有专属的事（屋檐下看雨），要有画面（雨丝、雪片、整屏一层冷色），要有后果（泥脚印要扫）。
2. **季节在现实里要够短**。一季 1 小时，玩家玩一晚上能见到两三季。一季一天，大多数人只认得一个季节。
3. **天气走同一个随机数源，按时段掷**。这样补算和一直玩结果相同。代价是每加一种随机数，旧测试里的骰子全挪一位：《起家》加天气时改了五条测试的预期（生育两条、婴儿拖拽一条、步长测试换种子、摘菜测试改成中午因为上午 11 点那天是冬天），每条写明原因。
4. **不冒的脏乱别掷骰子**。`spawn_per_day` 为 0 的种类每步不再抽随机数，省时间。
5. **打扫奖励给小，一天一次**。《起家》的营生学徒日薪 60 文，15 文够让玩家顺手去扫，不够让人靠扫地发家。

## 性能

天气让每次挑动作多乘几个系数。《起家》加季节天气的同一个提交里顺手提速：几个只跟季节、天气、地湿有关的判断按「季|天|湿」缓存，分数上限够不着候选池的动作直接跳过，结果和提速前逐个种子一致。预算的来龙去脉见 `pack-verification` 第 4 节。

## 验收

`pack-verification` 四样照做，再看这几样：

- `./game/tests/run.sh weather`、`dishes`、`clean_reward` 全过：四小时过四季、同一个种子天气相同、补算和一直玩天气相同、下雨少出门、雨天的事只在雨天、地湿不浇菜、雨后屋里有泥、积雪春天化、落叶、雪天才堆雪人、春天菜快冬天没有、冬天往灶和炕边凑、碗筷要收、放久了浪费、扫干净一天付一次。
- 平衡输出里看打扫奖励发了几次、一共多少钱，日记里看每季的事对不对（冬天没人在河边泡脚）。
- 每种天气在真窗口里看一眼：雨丝雪片盖不盖字、积雪那片底下有没有多画一块奶油色的底板（积雪不画底板）。
