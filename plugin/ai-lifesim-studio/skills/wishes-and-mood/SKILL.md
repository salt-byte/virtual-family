# 心愿与心情（wishes-and-mood）

小人什么都不想要，玩家就不知道该为谁做什么。心愿给玩家一个具体的事做：他想吃糖人，就去集市买；他想要书房，就攒钱盖。满足了，小人转过身朝屏幕招手道谢，这是给玩家的回报。

## 心愿长什么样

`game/packs/<id>/wishes.json`：

```json
{"id": "want_cake", "text": "想吃块桂花糕", "kind": "item", "item": "osmanthus_cake",
 "likes": ["嘴馋"], "weight": 3, "ttl_hours": 8, "joy": 15}
```

| `kind` | 怎么算满足 |
|---|---|
| `item` | 玩家买了那样东西，用在这个人身上 |
| `object` | 家里有了那种家具 |
| `room` | 那处地方盖好了 |
| `praise` | 玩家夸他一句 |
| `need` | 身体上的：某个需求低了冒出来（想吃口热饭、想好好睡一觉、想身子快些好），需求回升就算满足 |
| `married` / `baby` | 他成了亲 / 他添了孩子（`baby` 要等包里有生育） |

- `likes` 对上人的性格词，权重更高；对上 `dislikes` 的不会冒。
- `stages` 限年纪，婴儿不冒心愿。
- `ttl_hours` 到点没满足就过期；`joy` 是满足时心情涨多少。
- 一个人同时只挂一个心愿。身体上的心愿优先，会顶掉正挂着的心情心愿，不罚。

**写心愿**：「想 + 具体的东西」，短，玩家一眼知道去哪儿弄：想要个糖人、想要一本《三字经》、想做身新衣裳、想开块菜园。别写「想要幸福」这种没法满足的。每个 `item` 心愿对应的东西集市里要买得到，价钱要够得着（书 20–60、衣裳 30–80）。

## 心情怎么往下走

`pack.json` 里的几个数（《起家》的值）：

| 参数 | 值 | 意思 |
|---|---|---|
| `mood_low_below` | 25 | 心情低于这个算「低」 |
| `mood_sad_after_hours` | 6 | 低了这么久 → 难过 |
| `mood_depressed_after_hours` | 24 | 低了这么久 → 抑郁 |
| `mood_recover_above` / `mood_recover_hours` | 50 / 12 | 心情高于 50 连续 12 小时，抑郁才缓过来 |
| `mood_care_hours` | 12 | 多久没人理就开始掉 |
| `mood_neglect_per_hour` / `mood_neglect_floor` | 2.5 / 10 | 没人理时，自己找乐子能撑到的上限每小时降多少、最低降到哪 |
| `wish_miss_penalty` | 10 | 心情心愿过期扣多少 |

**一定要有「没人理」这条**。《起家》第一版没有：小人自己晒太阳、发呆、逗蚂蚁，心情一直在 99 附近，难过和抑郁永远不会发生。现在的规矩是：12 小时没人夸、没人给东西、没满足过心愿，他自己找的乐子就只能把心情撑到一个越来越低的上限。

抑郁时：干活只给钱不长进度，不冒新心愿，常做几样消沉的事（蒙着被子躺着不想动、对着碗发呆不动筷子、背过身去对着墙不说话），吃饭也少。抑郁本身不直接致死，但人不吃不睡，身体会跟着垮。夸他、给零嘴、满足心愿能把他拉回来。

**玩家不在的时候不罚**：离线补算期间不冒新心愿、过期不扣心情、不会滑进难过和抑郁，只算恢复。玩家关了游戏回来发现全家抑郁，只会觉得被坑。

## 验收

`pack-verification` 四样照做，再加两样：

- 平衡输出里看心愿冒了多少、满足多少、过期多少（《起家》20 户 3 天：348 / 296 / 24），以及有人难过、抑郁没有。有人照顾（模拟里的照料者会满足一部分心愿）时应该很少有人抑郁。
- 写一个「只管吃药、不管心情」的测试：大约第 2 天难过、第 3 天抑郁，给了零嘴之后能缓回来。
