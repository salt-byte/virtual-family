# 生育与代际（births-and-generations）

只结婚不生孩子，一家人过完一代就断了，按代解锁的旧事和「想要个孩子」的心愿也永远够不着。生育让家一代代往下传：夫妻怀上，孩子落地，大人抱着喂米汤、哄睡，孩子长大挑一行营生，成亲，再生下一代。

## 数据长什么样

`pack.json` 里一个 `births` 块，空或不写就没有生育（测试包 `_smoke` 靠这条保持不变）。《起家》：

```json
"births": {"fertile_age": [18, 40], "chance_per_day": 0.8, "pregnancy_years": 0.75,
           "beds": ["kang"], "surname_from": "father", "avoid_tag": "重活",
           "drain": {"energy": 1}, "guardian": true}
```

| 键 | 意思 |
|---|---|
| `fertile_age` | 妻子在这个年纪之间才可能怀上 |
| `chance_per_day` | 一对夫妻一天里怀上的机会，每个整点试一次；乘两人心情的平均（`praise_need` / 100）和较差那人的身体（`vital_need` / 100）。任一人生病或抑郁就是 0 |
| `pregnancy_years` | 怀多久，按包里的年岁钟算 |
| `beds` | 哪些物件算睡处，加起来的 `capacity` 是能睡几个人 |
| `surname_from` | 孩子随父姓还是随母姓 |
| `avoid_tag` | 孕妇不做带这个标签的动作 |
| `drain` | 怀着身孕时某个需求每小时多掉多少 |
| `guardian` | 最后一个大人死了、只剩孩子时，来一位远房亲戚 |

《起家》一年 4 个现实小时（`hours_per_year`），所以怀胎 0.75 年是 3 个小时，婴儿期（0–2 岁）8 个小时，18 岁成年在第 3 天。土炕 `"capacity": 3`，开局只有一铺。

**住处上限**：活着的每个人占一个睡处，肚子里的孩子也占一个。睡处满了就怀不上，界面提示一次「炕睡不下了，再添张炕才好添丁」（`ui.json` 的 `hint.no_bed`），家人面板里一直挂着。夫妻加一个孩子就把一铺炕睡满，想要第二个得先花 600 文再盘一铺，这是给玩家攒钱的一个理由。

**孩子落地**：一个 0 岁的人，代数是父母里较高那位加 1，记下父母。来一张「添丁」卡片，写名字、父母、第几代。离线期间生的，回来的总结里点名。

**远房亲戚**的代数比孩子里最高的那代低一代，跟孩子同姓，进门有卡片。没有这条，一场病带走两个大人，剩下一炕孩子没人喂，玩家只能看着全家饿死。

## 婴儿和照看

婴儿在 `actions.json` 里有自己的一套，`"stages": ["baby"]`、`"praiseable": false`：蜷在襁褓里睡、咿咿呀呀自己说话、满炕爬着找东西啃。饿了（`need_below` fed 40）就哇哇大哭，这是一条 `trouble`，基础分 20，盖过别的。

照看的动作用 `tends` 指向婴儿缺的那个需求：

```json
{"id": "feed_baby", "label": "抱着孩子一勺勺喂米汤", "kind": "daily", "duration_min": 20,
 "tends": {"fed": 50}, "stages": ["adult", "elder"]}
```

婴儿哪样缺得多，对应的照看动作分就高。大人会自己去，玩家也能把大人拖到婴儿身上。拨浪鼓这种逗乐的小孩也能做。

孕妇另有几样只在怀着时做的事（`"requires": {"pregnant": true}`）：扶着腰慢慢走两步、摸着肚子跟孩子说话、靠着被垛缝小衣裳。状态栏写「怀着身孕」。

## 代际

- 开了生育，每个没成亲的大人都会有人上门提亲，家里生的孩子长大才成得了亲，香火才接得下去。
- 家人面板按代排：第一代、第二代……娶进门的站在配偶旁边，死了的灰着写上享年，婴儿按月算岁数。
- 心愿 `baby`（想要个孩子）在孩子落地那刻满足。
- 旧事的 `generation_at_least` 解锁靠它。《起家》的「院里的小影子」要等第二代，生育做出来之前它永远解锁不了，测试却全过（见 `old-stories`）。

## 定数的时候想清楚

1. **一代人在现实里过多久**。按一年几个小时、几岁成年、几岁老，算出孩子落地后几天能成亲。《起家》是 3 天。太长，玩家看不到下一代；太短，一家人还没认熟就换了一茬。
2. **一天的机会给高**。0.8 乘上心情和身体，再被病、抑郁、睡处卡住，真实的生育比这个数慢得多。给低了，模拟几天也添不了一个孩子。
3. **睡处做成玩家能解开的锁**。睡处满了要告诉玩家为什么、怎么解（再买一张床），不能悄悄不生。
4. **孕妇的限制要轻**。只避开重活、多掉一点精神。卧床几个月这类写法会让一个大人几个小时什么都不干，钱跟着断。

## 性能

生育给每次挑动作都添了一点活。补算 48 小时一度超了上限，后来把孕妇和照看婴儿的筛选放进按年龄段缓存的动作表，每步只列一次婴儿，同一个种子出来的世界一步不差，速度回到加生育之前（提交 ac400ba）。性能预算是全部功能共用的，见 `pack-verification` 第 4 节。

## 验收

`pack-verification` 四样照做，再看这几样：

- `./game/tests/run.sh births` 全过：怀上到落地、病了或抑郁的夫妻不怀、过了岁数不怀、睡处满了不怀、孕妇不干重活、没人喂的婴儿会饿死、拖大人到婴儿身上会去喂、只剩孩子来亲戚、存档读档后夫妻和身孕都在。
- 用长跑模拟确认真实的一局里能出第二代、家里生的孩子能成年、挑上营生、有人提亲。只在测试里成立不算。
- 加了随机数的功能（天气、宠物）会挪动骰子，生育的测试最容易跟着变。《起家》加天气时，炕的测试改成最多等 3 小时等那次约 97% 的怀孕，生产的测试关掉生病（丈夫着了凉）。改预期要写明是骰子挪了，不是规则变了。
- 卡片、状态栏、家谱上的字跑 `python3 game/tools/build_font.py` 截字体。
