# 营生（livelihoods）

营生要改变小人每天做什么，不能只是名字和日薪不一样。《起家》的做法：每一行有自己的活，活落在具体的地方。木匠在柴房弹墨线、凿榫眼，豆腐坊天不亮就在灶间泡黄豆、点卤水，货郎在大门口摇拨浪鼓。玩家看一眼谁在哪儿干什么，就知道他是干哪行的。

## 数据长什么样

`game/packs/<id>/livelihoods.json`：

```json
{"id": "carpentry", "name": "木匠", "affinity": ["好侍弄", "spin_top", "hide_behind_door"],
 "levels": [
   {"name": "学徒", "daily_income": 60, "work_bonus_per_hour": 5, "progress_to_next": 260},
   {"name": "木匠", "daily_income": 150, "work_bonus_per_hour": 9, "progress_to_next": 640},
   {"name": "掌墨师傅", "daily_income": 300, "work_bonus_per_hour": 16, "progress_to_next": 0}]}
```

- `daily_income`：大人、老人每天的日薪，按整点分 24 份发；小孩不领。
- `work_bonus_per_hour`：干本行的活，按干的时长另给钱。
- `progress_to_next`：攒够就升一级，最后一级写 0。身体不好时干活只给钱、不长进度。
- `affinity`：这一行适合什么人。可以写性格词（对上人的 `likes`），也可以写动作 id（对上小孩常做的事）。

干活的动作在 `actions.json` 里带 `"work": {"track": "<营生 id>"}`，只有干这一行的人会做。写法照 `action-authoring`。

## 谁干哪一行

| 情况 | 规则 |
|---|---|
| 领养来的、娶进门的大人 | 一到家就分好：拿他喜欢的性格词对 `affinity`，喜欢的加分、讨厌的减分，取最高的；平手随机。领养卡片和进门那句话里写明「木匠 · 学徒」 |
| 家里生的小孩 | 成年前没有营生，只记下小时候做完了哪些事；到成年那一刻，挑 `affinity` 和这份记录最对得上的那一行 |
| 改行 | 家人面板里选，大人老人都能改。等级、进度、零头工钱全部清零，正在干的活停下 |
| 包里只有一种营生 | 以上都不发生，照旧随机分，不额外抽随机数（测试包 `_smoke` 靠这条保持不变） |

## 怎么排一行营生

1. **3 个等级**，名字是那个年代真有的叫法（学徒 → 木匠 → 掌墨师傅）。
2. **4–6 样活**，**至少 3 样在开局就盖好的屋里能做**，不然新来的人一入行就没活干（有测试）。其余的可以绑在要买的营生家具上（刨木凳、药碾、绣绷、豆腐箱、货担），或者绑在待加盖的地方。营生家具顺带给了玩家一个花钱的去处。
3. **有自己的时辰**：豆腐坊清早 5 点到中午，读书白天。
4. **`affinity` 别撞车**：两行只挂同一个性格词时，有这个性格的人总落到排在前面的那一行。《起家》里郎中和织绣都只挂「喜静」，模拟 40 个人，一个郎中都没有。每行至少挂一个别的行没有的词或童年动作。

## 加了营生以后调钱

活变多了，大人花在干活上的时间也多，钱会涨。《起家》新营生的活一开始 `base` 给到 10，中位存款涨到 1943；降到 4（读书的念书是 14）才回到 1555。只调包里的数据。验收看 `pack-verification`，另外看两样：

- `balance_cli` 输出里各行营生的人数分布：不能有哪一行一直是 0。
- 每一行都能升到第 2 级（`avg_level` ≥ 0.6）。
